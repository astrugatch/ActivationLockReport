The purpose of this tool is to check your own ASM device pool for devices with Activation Lock enabled. 
It requires an API account in ASM.
It accepts a CSV file of serial numbers and outputs a CSV of status information.

This was entirely generated with Gemini. It has been tested as working but please verify all code yourself.

This is released with no support or warranty. Please feel free to fork the repo and do with it as you want. 

I am including a compiled binary. I do not have an Apple Developer account so it is not signed and will throw security warnings.
